1.  SQL vs NoSQL

SQL: - Structured data (tables, rows, columns) - Fixed schema - Uses SQL
language - Vertical scaling - Examples: MySQL, PostgreSQL

NoSQL: - Unstructured/semi-structured data - Flexible schema - JSON-like
queries - Horizontal scaling - Examples: MongoDB, Cassandra



2.  CAP Theorem

CAP = Consistency, Availability, Partition Tolerance

-   Consistency: Same data on all nodes
-   Availability: Every request gets response
-   Partition Tolerance: Works despite network failure

Only 2 out of 3 can be guaranteed: - CP (Consistency + Partition) - AP
(Availability + Partition)

4.  Why BSON instead of JSON

-   Faster processing (binary format)
-   Supports more data types (Date, ObjectId, Binary)
-   Efficient storage
